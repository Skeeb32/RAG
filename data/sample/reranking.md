# Reranking
The improved configuration applies cross-encoder/ms-marco-MiniLM-L6-v2 to the hybrid retrieval candidates and returns the top three passages. A cross-encoder jointly reads a question and passage, making it more expensive than comparing precomputed vectors. Reranking can improve ordering but cannot recover a document absent from the candidate set. Baseline uses the same hybrid candidates and returns the top three without reranking. The Reranker protocol allows another implementation to be substituted. Measure latency as well as retrieval quality; extra model computation is not automatically worthwhile.
